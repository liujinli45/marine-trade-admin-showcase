# 界面截图

> 全部截图取自一套**独立演示实例**，与任何生产环境无关。
> 库内数据由项目自带的演示种子脚本灌入：账号一律 `*@example.com` 或 `*@example`、
> 订单号一律 `DEMO-2026-###`、客户与工厂均为虚构主体、公司抬头为通用演示名称。
> 不含任何真实客户、订单、金额、合作方与服务器信息。

截图浏览顺序按业务主线排列：**订单履约 → 客户与供应商 → 报价 → 经营分析 → 组织权限 → 三语**。

---

## 1. 订单履约主线

### 1.1 首页 · 订单履约工作台

![首页仪表盘](../assets/screenshots/02-dashboard.jpg)

「今日待办」把**逾期订单 / 7 天内到期 / 未安排履约计划**三类风险直接前置；
下方按「最早逾期日期」排序列出高风险订单，点进去即可补充履约节点。
待办口径由后端按当前账号的数据范围计算，不是前端本地过滤。

### 1.2 订单管理

![订单管理](../assets/screenshots/03-orders.jpg)

状态、收款状态、负责人、客户、日期区间多维筛选，服务端分页；
顶部提供批量导出（Excel）与已选订单的单证批量生成入口。

### 1.3 订单详情 · 订单详情

![订单详情](../assets/screenshots/04-order-detail.jpg)

订单主档把**金额构成与财务标记**集中在一屏：订单总额、客户报价、预估利润、
定金与工厂应付、价格是否含税、是否需要报关、定金是否到账、利润是否已确认。
这些标记是「利润确认」规则的状态位——未确认的利润不计入经营口径。

### 1.4 订单详情 · 履约节点

![履约节点](../assets/screenshots/05-order-workflow.jpg)

节点按类型（采购 / 生产 / 检验 / 发运）承载计划日期与实际完成时间，
逾期与即将到期由服务端统一判定；改计划日期必须填写变更原因，原计划日期被保留留痕。

### 1.5 订单详情 · 款项汇总

![款项汇总](../assets/screenshots/06-order-finance.jpg)

定金 / 尾款的确认动作、付款记录（含作废，不物理删除）、订单成本明细与报价面板。
金额写入接口全部要求携带 `Idempotency-Key`，重复提交不会产生第二笔流水。

### 1.6 订单详情 · 外贸单证

![外贸单证](../assets/screenshots/07-order-documents.jpg)

商业发票 / 装箱单字段维护：出口商与收货人、通知方、贸易术语、唛头、包装件数、
净重/毛重/体积、HS 编码与货物描述。人民币发票取订单金额，外币发票取同币种客户报价，
单价按数量分摊——口径写在服务端，不由前端拼接。

## 2. 客户与供应商

### 2.1 客户管理

![客户管理](../assets/screenshots/08-customers.jpg)

客户档案列表，含分类（重点/普通/潜在）、信用等级、来源渠道、负责人归属与标签；
支持 Excel 导入导出、重复客户检测与合并、销售阶段流转。

### 2.2 客户详情

![客户详情](../assets/screenshots/09-customer-detail.jpg)

客户 KPI（订单数 / 成交总额 / 预计利润 / 待收款 / 进行中报价 / 逾期节点）与
业务动态、联系人、报价管理、历史订单分栏。

### 2.3 工厂管理

![工厂管理](../assets/screenshots/10-factories.jpg)

供应商档案与经营类目，关联订单数与累计交易额由后端聚合。

### 2.4 工厂详情与产品库

![工厂详情](../assets/screenshots/11-factory-detail.jpg)

![工厂产品库](../assets/screenshots/12-factory-products.jpg)

工厂产品库维护采购价 / 销售价 / MOQ / 包装 / 重量体积，可据此快速生成报价明细。

---

## 3. 报价工作台

![报价工作台](../assets/screenshots/13-quotation-workspace.jpg)

左侧为结构化表单（卖方资料 / 客户资料 / 明细 / 金额与条款），右侧是 **A4 实时预览**。
报价支持多版本：版本号 + 行锁防并发覆盖，冲突时保留当前表单而不是静默覆盖；
支持多币种与附加金额（运费、折扣、税率），金额按整数分计算并对非法输入直接拒绝。

---

## 4. 经营分析

![报表统计](../assets/screenshots/14-stats.jpg)

四个分栏：经营概览（销售与回款）、利润分析（成本与毛利）、履约效率（进度与风险）、
市场洞察（来源与产品）。所有统计都经过同一套数据范围函数，
业务员只能看到自己与直属团队的数据。

---

## 5. 组织与权限

![用户与权限](../assets/screenshots/15-users.jpg)

用户与销售员、经理—销售两级团队结构、角色与菜单权限、工作语言与账号数据归属。
菜单权限以「初始化脚本 + 前端预设 + 后端校验」三方对齐，由契约测试钉死，
避免「保存一次权限就静默吊销部分账号菜单」。

![个人中心](../assets/screenshots/16-profile.jpg)

![消息中心](../assets/screenshots/17-messages.jpg)

通知按 **i18n key + JSON 参数** 落库（`title` 存 key、`content` 存参数），
展示时按当前语言渲染，切换界面语言时历史消息一并切换；
点击消息按模块权限跳转，无权访问的模块直接拦截。

## 6. 三语界面

![登录页](../assets/screenshots/01-login.jpg)

![首页 · English](../assets/screenshots/18-dashboard-en.jpg)

![订单详情 · English](../assets/screenshots/19-order-detail-en.jpg)

![报表统计 · English](../assets/screenshots/20-stats-en.jpg)

界面为中文 / 英文 / 俄文三语。接口只回稳定的大写错误码，文案在前端按语言渲染，
因此多语言不会出现「后端返回的英文直接透传」；配套硬编码中文扫描 + 英文散文全量普查两道门禁。
